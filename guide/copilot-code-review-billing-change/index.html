Copilot code reviewの料金は誰に？12月30日の変更

2026年11月27日・SSS運営（松任谷・ゴリラ）・SSSの案内を含みます

この記事はSSS運営が書いた記事です。SSSの案内を含みます。

先に結論

Copilot code reviewの料金は、請求先を選んで保存していない組織の場合、2026年12月30日から扱いが変わります。有料のCopilotライセンスを持つメンバーのレビュー分は、原則として、リポジトリを所有する組織に請求されます。対象はCopilot BusinessかCopilot Enterpriseを使う組織と企業で、いまの形を続けたい管理者は、その日より前に請求先としてMemberを選んでおく必要があります。

  • 変わるのは、請求先をまだ選んでいない場合の既定の扱いです。
  • すでにMemberかOrganizationを選んでいれば、その選択が続きます。
  • ライセンスを持たないメンバー向けの別の設定は変わりません。
  • 組織への請求にすると、組織の支出が増える可能性があります。

SSSでは、AIの料金や設定の変更を自分の使い方に当てはめる作業を、もくもく作業会に持ち込めます。SSSを見る→

Copilot code reviewの請求で何が発表されたのか？

発表元はGitHubです。公式の更新情報であるGitHub Changelogに、2026年11月25日付で掲載されました。内容は請求先の既定を変えるというGitHubの発表で確認できます。

Copilot code reviewは、コードの変更をCopilotに見てもらうレビューの機能です。今回の発表は機能の追加ではなく、料金をどこに請求するかについての変更です。

現在は、請求先の選択を保存していない場合、有料ライセンスを持つメンバーのレビューには、そのメンバー自身のCopilotの利用枠が使われます。12月30日からは、未選択のままだと、リポジトリを持っている組織の負担に切り替わります。

つまり、何も操作をしなくても、支払う側が個人の枠から組織へ移る場合があるということです。レビューを頼む人の手順だけを見ていると気づきにくいので、請求を管理する人に伝わっているかを確かめてください。

何がどう変わるのか？

自分に関係があるかは、使っているプランと、請求先を保存したかどうかで分かれます。

いまの状態12月30日からの扱い
Memberを選んで保存しているメンバーの利用枠を使う形が続く
Organizationを選んで保存している組織への請求が続く
どちらも保存していない原則として組織への請求になる

どちらも保存していなくても、例外があります。AI Creditsの有料利用を有効にしていないアカウント、請求がロックされているアカウント、請求先となる顧客情報がないアカウントは、Memberに設定されると発表されています。

また、変更の日までは、未選択の項目には Default (Member) という表示と、変更を知らせる案内が出ます。表示にMemberの文字があっても、自分で選んで保存した状態とは違います。続けたい扱いがあるなら、どちらかをはっきり選んで保存してください。

企業（Enterprise）側で設定を管理している場合は、企業のオーナーが請求先を決めます。組織の担当者の画面で変えられないときは、上の管理者に確認してください。

仕事や副業でどうやって確認するか？

少人数の会社や、業務委託で組織に参加している副業の方は、次の順番で確かめると迷いにくくなります。

  1. プランと立場を確かめる。自分や取引先の組織が、Copilot BusinessかCopilot Enterpriseを使っているかを見ます。設定を変える権限がない場合は、管理者に発表のURLを送ります。
  2. Copilotのポリシー設定を開く。発表では、企業か組織のCopilotのポリシー設定で選ぶと案内されています。どちらの階層で管理しているかを先に確かめます。
  3. 請求先の状態を見る。保存済みの選択があるのか、未選択を示す表示のままなのかを確認します。
  4. 請求先を選んで保存する。メンバーの利用枠を使う形を続けるならMember、組織でまとめて払うならOrganizationです。
  5. 関係者に知らせる。どちらにしたか、いつ決めたかを短く残しておくと、後で請求を見たときに説明できます。

管理者に連絡するときは、次の二点を書き、発表のURLを添えると用件が伝わります。請求先の既定が2026年12月30日から変わること。MemberとOrganizationのどちらにするかを、その日より前に決めて保存してほしいことです。

どちらを選ぶかは、費用を誰が持つ約束になっているかで考えます。会社の仕事のレビューを会社で払うならOrganizationが候補になります。組織の支出を増やさず、いまの形を続けたいならMemberが候補です。業務委託の方は、自分の利用枠が仕事先のレビューに使われてよいのかも、あわせて相談しておくと行き違いを減らせます。

使う前に確かめることは？

料金。組織への請求には、AI Creditsの有料利用を有効にする必要があります。発表では、組織の支出が増える可能性があるとされています。この記事では金額を扱いません。自分の組織でいくらになりそうかは、請求を管理する人と確認してください。

対象のプラン。今回の請求先の変更は、Copilot BusinessとCopilot Enterpriseを使う組織と企業が対象です。

対象の人。変わるのは、有料のCopilotライセンスを持つメンバーのレビューの扱いです。ライセンスを持たないメンバー向けの設定は別なので、二つを混同しないようにしてください。

期限。いまのメンバー請求を続けたい場合は、12月30日より前にMemberを選びます。権限を持つ人が別にいる組織では、依頼してから保存されるまでの時間も見込んで、早めに声をかけてください。

Copilotの別の機能を調べている方には、GitHub Copilot Fusionとは？使い方と仕事・副業で試す手順もあります。コードを書いた経験が少なく、AIに指示を出して自動化するところから始めたい方は、Claude Code初心者の使い方：非エンジニアが最初の自動化に進む手順が入口になります。

このテーマをSSSでどう実践するか？

SSSは、Discordで運営しているAIコミュニティです。この記事の確認作業は、毎日開催のもくもく作業会に持ち込めます。自分の使っているAIの道具を書き出し、誰の支払いになっているか、いつ条件が変わるかを表にする作業から始められます。

設定画面のどこを見るかで手が止まったら、日中のAI実践会（不定期・月4〜5回）で、作業会のように手を動かしながら一緒に確かめることを試せます。毎日のAIニュースと講義アーカイブもあります。扱っているテーマには、AI自動化や企業へのAI導入が含まれます。画面を見せるときは、会社の名前や請求の情報を隠してください。料金は月額2,980円（税込）で、いつでも解約できます。

よくある質問

Q. 個人でCopilotを契約しているだけでも対象ですか？

今回の発表が対象にしているのは、Copilot BusinessかCopilot Enterpriseを使う組織と企業です。個人で契約しているだけの場合の変更は、この発表には書かれていません。ただし、仕事先の組織からライセンスを受けて使っているなら、その組織の設定が関係します。

Q. すでに請求先を選んでいる場合、何かする必要はありますか？

保存済みのMemberまたはOrganizationの選択は、そのまま続きます。意図した方になっているかを一度見ておくと安心です。

Q. ライセンスを持たないメンバーのレビューも変わりますか？

ライセンスを持たないメンバー向けの設定は別に用意されていて、今回の変更では変わらないと発表されています。

Q. 12月30日を過ぎたら設定は変えられませんか？

期限を過ぎた後の変更の可否は、この発表には書かれていません。発表が案内しているのは、いまのメンバー請求を続けたい場合に、12月30日より前にMemberを選ぶことです。
